LINEAR DATA STRUCTURE

Array

Elements are stored in indexed positions.

Definition

An array stores elements of the same type in contiguous memory locations.

Features

Indexed access • Fixed size • Fast direct access • Same data type

Types

One-dimensional • Two-dimensional • Multidimensional

Applications / Real-life Example

Real-life example: numbered seats or lockers. Arrays are also used for marks, temperatures and lists of IDs.

Operations
Insert • Delete • Search • Display

LIFO

Stack

Last In, First Out — the last element inserted is removed first.

Definition

A stack is a linear data structure that follows LIFO (Last In, First Out).

Features

LIFO • Push and Pop operations • Access through TOP

Types

Static stack • Dynamic stack

Applications / Real-life Example

Real-life example: a stack of plates. It is also used for browser history, undo operations and function calls.

TOP
Push adds an element to the top.
Pop removes the top element.

FIFO

Queue

First In, First Out — the first element inserted is removed first.

Definition

A queue is a linear data structure that follows FIFO (First In, First Out).

Features

FIFO • Insertion at rear • Deletion at front

Types

Simple queue • Circular queue • Priority queue • Deque

Applications / Real-life Example

Real-life example: people waiting at a ticket counter. Queues are also used in printers and task scheduling.

FRONT → REAR
Enqueue adds at the rear.
Dequeue removes from the front.

NODES + LINKS

Linked List

A sequence of nodes where each node stores data and a link to the next node.

Definition

A linked list is made of nodes where each node stores data and a link to the next node.

Features

Dynamic size • Nodes connected by links • Easy insertion and deletion

Types

Singly • Doubly • Circular

Applications / Real-life Example

Real-life example: a music playlist where each song points to the next. Linked lists are also used in memory management.

Example
HEAD → [10|next] → [20|next] → NULL

NON-LINEAR

Binary Search Tree

Smaller values go left and larger values go right.

Definition

A tree is a non-linear hierarchical structure. In a Binary Search Tree, smaller values go left and larger values go right.

Features

Hierarchical structure • Root and child nodes • Efficient BST searching

Types

Binary tree • Binary Search Tree • AVL tree • Heap

Applications / Real-life Example

Real-life example: computer folders or a family hierarchy. Trees are also used in databases and searching.

Traversals
In a BST: Left < Root < Right

Graph

A graph contains vertices connected by edges.

Definition

A graph contains vertices (nodes) connected by edges.

Features

Vertices and edges • Represents relationships • BFS and DFS traversal

Types

Directed • Undirected • Weighted • Unweighted

Applications / Real-life Example

Real-life example: a road map where cities are vertices and roads are edges. Social and computer networks also use graphs.
